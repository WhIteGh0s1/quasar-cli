# ◆ Квазар в терминале

VPN одной командой. Разрешение Windows спрашивается один раз — дальше Квазар держит подключение сам, даже после перезагрузки.

```powershell
irm whitegh0s1.github.io/quasar | iex
```

Потом в новом окне терминала:

```
quasar
```

Вставьте ссылку на свою подписку — и всё. Стрелки — выбор сервера, Enter — подключиться, Пробел — включить или выключить, Q — выйти (VPN останется включённым).

| Команда | Что делает |
| --- | --- |
| `quasar` | открыть Квазар |
| `quasar on` / `quasar off` | включить / выключить |
| `quasar ls`, `quasar ping` | серверы, с пингом |
| `quasar use 3` | выбрать сервер |
| `quasar sub <ссылка>` | своя подписка |
| `quasar uninstall` | удалить совсем |

Windows 10 и 11, x64. Внутри — mihomo и Xray.
